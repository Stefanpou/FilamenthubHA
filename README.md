# FilamentHub – Home Assistant-tilføjelse

Filament-lager og dashboard til **Bambu Lab**-printere (X1C, X1E, P1S, P1P, P2S, A1, A1 mini, H2D, H2S, X2D),
direkte i Home Assistant. Forbinder via Bambu Cloud. Understøtter aarch64 (Raspberry Pi) og amd64.

## Installation

[![Åbn din Home Assistant og tilføj arkivet.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FStefanpou%2FFilamenthubHA)

1. Indstillinger -> Tilføjelser -> Tilføjelsesbutik -> ⋮ -> Arkiver
2. Tilføj `https://github.com/Stefanpou/FilamenthubHA`
3. Installer **FilamentHub**, start den og åbn den fra sidepanelet.

## English

Filament inventory and Bambu Lab printer dashboard as a Home Assistant add-on (Bambu Cloud only; aarch64 and
amd64). Add `https://github.com/Stefanpou/FilamenthubHA` as an add-on repository, install **FilamentHub**,
start it and open it from the sidebar.
